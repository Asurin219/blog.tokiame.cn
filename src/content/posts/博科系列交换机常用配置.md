# 初始化配置
1. 这次配置的是一台FC交换机，来自华为的OceanStor SNS3664。它的默认管理IP地址为10.77.77.77，用户名为 `admin`，默认密码是 `Huawei12#$`。将电脑通过Console线直连交换机的串口，或配置好同网段IP地址后通过网线直连交换机的管理口，即可进行配置。
2. 连接到交换机后，使用 ``ipaddrset`` 命令修改管理IP地址：
   ```bash
   SNS3664:FID128:admin> ipaddrset
   DHCP [Off]:
   Ethernet IP Address [10.77.77.77]:172.21.46.5
   Ethernet Subnet mask [255.255.255.0]:
   Gateway IP Address [10.77.77.1]:172.21.46.1
   IP address is being changed...
   ```
3. 使用 `switchname` 修改交换机的主机名：
   ```plain
   SNS3664:FID128:admin> swichname <主机名>
   ```
   主机名称最大支持30个字符。

# 常见配置
## 建立映射关系
1. 创建配置
   ```bash
   cfgcreate <配置名称>
   ```

1. 创建别名
   ```bash
   aliascreate "<别名>" <成员设备WWPN>
   aliascreate "<别名>" <交换机域ID,端口索引号>（如果有多个成员，成员间用;分隔）
   ```

1. 使用别名创建zone
   ```bash
   zonecreate <区域名> <成员>
   成员可以是wwpn，也可以是别名。可以使用通配符*匹配多个成员，多个成员间用;分隔。
   将Zone加入cfg
   cfg add <配置名称>,<Zone名称>
   ```
2. 保存配置：
   ```bash
   cfgsave
   ```

3. 使能配置：
   ```bash
   cfgenable
   ```

需要注意的是，保存配置后，配置并不会立即生效，仅仅是系统经过检查以后将配置文件保存到交换机中。只有当使用了 `cfgenable` 命令使能配置文件以后，配置才会生效。在生产环境下，通常建议先将配置保存再使能，避免配置出现错误导致业务中断。
